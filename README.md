# چت فارسی با gpt-oss:20b (Next.js + Ollama)

یک رابط چت خیلی ساده که در مرورگر باز می‌شود و مستقیم با مدل `gpt-oss:20b` که روی خود سیستم شما از طریق **Ollama** اجرا می‌شود صحبت می‌کند. دیگر لازم نیست خروجی فارسی را در PowerShell ببینید.

## پیش‌نیازها

1. **Node.js** نسخه ۱۸ به بالا نصب باشد.
   بررسی: `node -v`
2. **Ollama** نصب باشد و مدل دانلود شده باشد:
   ```
   ollama pull gpt-oss:20b
   ```
3. سرویس Ollama در حال اجرا باشد (معمولاً بعد از نصب خودش به‌صورت سرویس بک‌گراند اجرا می‌شود؛ اگر نبود دستور زیر را در یک ترمینال جدا اجرا کنید و باز بگذارید):
   ```
   ollama serve
   ```

## نصب و اجرا

در پوشه پروژه (همین پوشه‌ای که این فایل در آن است):

```bash
npm install
npm run dev
```

بعد از اجرا، در مرورگر بروید به آدرس:

```
http://localhost:3000
```

و شروع به چت کنید. پاسخ‌ها به‌صورت زنده (استریم) و در همان صفحه نمایش داده می‌شوند.

## اگر پاسخی نیامد

اگر پیام خطا دیدید، معمولاً یکی از این‌هاست:

- Ollama در حال اجرا نیست → دستور `ollama serve` را اجرا کنید.
- مدل نصب نیست → دستور `ollama pull gpt-oss:20b` را اجرا کنید.
- مدل روی پورت یا آدرس دیگری اجرا می‌شود → آدرس `OLLAMA_URL` را در فایل `app/api/chat/route.js` تغییر دهید (پیش‌فرض `http://127.0.0.1:11434`).

## ساختار پروژه

```
app/
  layout.js        فونت و تنظیمات پایه صفحه (راست‌به‌چپ)
  globals.css       استایل ساده رابط
  page.js           رابط چت (فرانت‌اند)
  api/chat/route.js  واسط بین مرورگر و Ollama (بک‌اند داخل Next.js)
```

نیازی به کد پایتون جداگانه نیست؛ خود Next.js هم فرانت‌اند و هم درخواست به Ollama را انجام می‌دهد.
