# چت‌بات فروشگاهی — رابط چت محلی مبتنی بر Ollama

چت‌بات فارسی، راست‌چین (RTL) و کاملاً محلی برای فروشگاه، ساخته‌شده با Next.js
و متصل به یک مدل زبانی که روی سخت‌افزار خودتان از طریق [Ollama](https://ollama.com)
اجرا می‌شود. چون همه‌چیز محلی اجرا می‌شود، نه اینترنت لازم است و نه داده‌ای
از فروشگاه یا مشتری به سرویس بیرونی ارسال می‌شود.

> این README بر اساس کد رابط کاربری (`layout.js`, `page.js`, `chat.css`) نوشته
> شده است. بخش‌های مربوط به بک‌اند و منطق فروشگاهی (جست‌وجوی محصول، سفارش و
> غیره) را ندیده‌ام، پس بخش «قرارداد API» را با چیزی که خودتان پیاده‌سازی
> کرده‌اید/می‌کنید تطبیق دهید.

## ویژگی‌ها

- رابط کاملاً راست‌چین به فارسی — از جهت متن تا جهت اسکرول‌بار
- استریم پاسخ به‌صورت لحظه‌ای (رویدادهای NDJSON) از `/api/chat`
- نمایش زنده‌ی زنجیره‌ی فکر مدل (thinking)، قابل جمع‌شدن، با تایمر
- گزارش فراخوانی ابزارها (tool calls) با وضعیت در حال اجرا / انجام‌شده / خطا
- انتخاب‌گر مدل سفارشی (لیست از `/api/models`)، بدون وابستگی به `<select>` بومی مرورگر
- تم روشن / تاریک / پیرو سیستم، بدون چشمک‌زدن هنگام بارگذاری صفحه
- ادامه‌ی گفتگو، مدل انتخابی و تنظیمات بین بارگذاری‌های صفحه (`localStorage`)
- بازتولید پاسخ (regenerate)، توقف پاسخ در حال تولید (stop)، گفتگوی تازه
- رندر مارک‌داون (جدول، بلوک کد با دکمه‌ی کپی) با محافظت در برابر HTML/تصاویر
  ناامنی که ممکن است از خروجی ابزارها تزریق شوند
- فونت‌های Vazirmatn و JetBrains Mono به‌صورت محلی سرو می‌شوند — بدون درخواست
  به گوگل هنگام اجرا

## پیش‌نیازها

- Node.js (نسخه‌ی مورد نیاز Next.js پروژه)
- [Ollama](https://ollama.com) نصب‌شده و در حال اجرا روی همان دستگاه
- حداقل یک مدل pull‌شده در Ollama — پیش‌فرض پروژه `gpt-oss:20b` است

```bash
ollama pull gpt-oss:20b
```

## اجرا

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## فایل‌های اصلی رابط کاربری

| فایل | نقش |
|---|---|
| `layout.js` | چیدمان ریشه؛ بارگذاری فونت‌ها با `next/font` و اسکریپتی که تمِ ذخیره‌شده را پیش از اولین رندر اعمال می‌کند |
| `page.js` | کل منطق و رابط چت — مدیریت استریم، پنل تفکر، انتخاب‌گر مدل، تم، اسکرول |
| `chat.css` | استایل‌ها — توکن‌های تم با `light-dark()`، پشتیبانی کامل RTL (از جمله اسکرول‌بار سمت راست) |

## قرارداد API مورد انتظار

رابط کاربری دو مسیر را از بک‌اند انتظار دارد:

**`GET /api/models`**
```json
{ "models": ["gpt-oss:20b", "qwen3:8b"] }
```
یا در صورت خطا: `{ "error": "..." }`

**`POST /api/chat`** — بدنه‌ی درخواست:
```json
{
  "messages": [{ "role": "user", "content": "..." }],
  "model": "gpt-oss:20b",
  "think": true
}
```
پاسخ یکی از دو حالت زیر است:
- **استریم NDJSON** — هر خط یک رویداد JSON با یکی از انواع
  `thinking` / `content` / `tool` / `stats` / `error`
- **JSON یک‌باره** (fallback بدون استریم): `{ content, thinking, toolLog }`

## محدودیت‌های شناخته‌شده

- استایل‌ها از `light-dark()` استفاده می‌کنند؛ به Chrome 123+، Firefox 120+
  یا Safari 17.5+ نیاز دارد.
- پیام‌های خطا و placeholderهای رابط (مثل «ارتباط با سرور قطع شد») به تاریخچه‌ی
  ارسالی به مدل اضافه نمی‌شوند؛ فقط برای نمایش‌اند.
